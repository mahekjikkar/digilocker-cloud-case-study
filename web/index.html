DigiLocker registry

A working model of India's document wallet. The registry stores a pointer to each document, never the document itself, and fetches it live from the issuing department. Take one department offline and watch what happens to the other.

Try this

  1. Open the driving licence. Note the time, usually under 100 ms.
  2. Set CBSE to Offline.
  3. Open a CBSE marksheet three times. Each fails only after a real call is attempted.
  4. Open it once more. The breaker is open now, so no call is made at all.
  5. Open the driving licence again. PARIVAHAN is unaffected. Set CBSE back to Healthy, wait ten seconds, then open the marksheet to watch it recover.
